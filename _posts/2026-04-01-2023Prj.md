## 게임 서버 개발자 포트폴리오

2023년에 게임서버 개발자를 준비하며 작성한 포트폴리오입니다.
- 개발 기간: 2023.01 ~ 2023.05

C++ 기반의 MMO 게임 서버와 IOCP 네트워크 라이브러리를 직접 구현하였습니다.  

- Language: C++, C#
- Database: MySQL, Redis
- Network: IOCP
- Platform: Windows

전체 소스코드는 GitHub에서 확인할 수 있습니다.  
[💻 프로젝트 소스코드](https://github.com/TrynBug/HSKim_proj)

### 목차

1. MMO 게임 서버 
2. IOCP 네트워크 라이브러리 
3. 게임 콘텐츠 전용 IOCP 네트워크 라이브러리 
4. 서버 모니터링 클라이언트 (C#)
5. Lock-free Stack
6. TLS 메모리풀 
7. A* 길찾기 
8. Jump Point Search 길찾기
